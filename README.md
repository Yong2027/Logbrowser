# Logbrowser

### 介绍
Logbrowser是一款功能强大的日志浏览工具，它支持日志的合并，搜索，过滤，高亮，书签和导入导出等功能。同时支持配置持久化和批量导入导出多个文件，非常适合大型软件系统的日志定位与分析。 对比Nodetepad++，使用更灵活，功能更强大。

### 功能说明
1.支持正则表达式，通配符，全词匹配和大小写搜索和过滤；<br> 
2.支持最多6个过滤集。每个过滤集最多支持8个关键词输入，不同过滤集之间的关系为“或”，而每个过滤集内不同关键词输入之间的关系为“与”；<br> 
3.支持动态切换不同的背景颜色高亮显示；<br> 
4.支持两种类型书签：点击行首隐式添加书签和通过GUI显示添加书签；<br>
5.支持字体放大和缩小；

### 常用快捷键
**Ctrl+C:** 拷贝<br> 
**Ctrl+V:** 粘贴<br> 
**Ctrl+O:** 打开多个文件<br>
**Ctrl+K:** 打开文件夹<br>
**Ctrl+S:** 另存为...<br>
**Ctrl+ Mouse Wheel Up:** 放大<br>
**Ctrl+ Mouse Wheel Down:** 缩小<br>
**PageUp or UpArrow:** 向上翻页<br>
**PageDown or DownArrow:** 向下翻页<br>
**Home or LeftArrow:** 跳到行首<br>
**End or RightArrow:** 跳到行尾<br>
**Click line numer:** 增加书签<br>
**F2 or Shitf + F2:** 向上/向下浏览书签<br>
**Ctrl+Shift+F2:** 删除所有书签<br>
